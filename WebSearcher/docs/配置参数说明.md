# WebSearcher 配置参数详解

本文档详细说明WebSearcher MCP服务器的所有配置参数及其用途。

## 📋 配置方式

WebSearcher支持两种配置方式：

1. **环境变量**：通过`.env`文件或系统环境变量
2. **MCP客户端配置**：在Claude Desktop等客户端的配置文件中直接设置

## 🔧 核心配置参数

### 1. SEARCH_ENGINE（搜索引擎选择）

**说明**：指定要使用的搜索引擎

**类型**：字符串

**可选值**：
- `google` - Google自定义搜索API
- `bing` - Bing网页搜索API  
- `serpapi` - SerpAPI（支持多个搜索引擎）

**默认值**：`serpapi`

**是否必需**：是

**示例**：
```env
SEARCH_ENGINE=serpapi
```

**说明**：
- `serpapi`：推荐初学者使用，配置简单，支持多个搜索引擎
- `google`：需要Google Cloud账号和自定义搜索引擎配置
- `bing`：需要Azure账号和Bing Search API订阅

---

### 2. SERPAPI_KEY（SerpAPI密钥）

**说明**：SerpAPI服务的API密钥

**类型**：字符串

**默认值**：无

**是否必需**：当`SEARCH_ENGINE=serpapi`时必需

**获取方式**：
1. 访问 [https://serpapi.com/](https://serpapi.com/)
2. 注册账号
3. 在Dashboard中获取API密钥

**免费额度**：100次搜索/月

**示例**：
```env
SERPAPI_KEY=1234567890abcdef1234567890abcdef1234567890abcdef1234567890abcdef
```

**注意事项**：
- 密钥长度通常为64个字符
- 不要在代码中硬编码密钥
- 不要将包含真实密钥的`.env`文件提交到版本控制

---

### 3. GOOGLE_API_KEY（Google API密钥）

**说明**：Google Custom Search API的密钥

**类型**：字符串

**默认值**：无

**是否必需**：当`SEARCH_ENGINE=google`时必需

**获取方式**：
1. 访问 [Google Cloud Console](https://console.cloud.google.com/)
2. 创建项目
3. 启用Custom Search API
4. 创建API密钥

**免费额度**：100次搜索/天

**示例**：
```env
GOOGLE_API_KEY=AIzaSyABCDEFGHIJKLMNOPQRSTUVWXYZ1234567
```

---

### 4. GOOGLE_SEARCH_ENGINE_ID（Google搜索引擎ID）

**说明**：Google自定义搜索引擎的唯一标识符

**类型**：字符串

**默认值**：无

**是否必需**：当`SEARCH_ENGINE=google`时必需

**获取方式（详细步骤）**：

#### 步骤1：创建自定义搜索引擎

1. 访问 [Google Programmable Search Engine](https://programmablesearchengine.google.com/)
2. 使用你的Google账号登录
3. 点击 **"Add"** 或 **"创建搜索引擎"** 按钮

#### 步骤2：配置搜索引擎

1. **搜索引擎名称**：输入一个描述性名称，例如 "WebSearcher MCP"
2. **要搜索的网站**：
   - 输入 `www.google.com`（这是一个占位符）
   - 勾选 **"搜索整个网络"** 选项
3. **语言**：选择你需要的语言（如中文、英文）
4. 点击 **"创建"** 按钮

#### 步骤3：获取搜索引擎ID

1. 创建完成后，会自动跳转到搜索引擎的控制面板
2. 在左侧菜单中点击 **"概览"** 或 **"Overview"**
3. 找到 **"搜索引擎 ID"** 或 **"Search engine ID"** 字段
4. ID格式通常为：
   - 短格式：`a1b2c3d4e5f6g7h8i`
   - 长格式：`012345678901234567890:abcdefghijk`
5. 点击复制按钮或手动复制这个ID

#### 步骤4：启用"搜索整个网络"（重要）

1. 在控制面板中，点击左侧的 **"设置"** 或 **"Setup"**
2. 在 **"基本信息"** 部分，确保：
   - **"搜索整个网络"** 选项已启用
   - 如果看到 "要搜索的网站" 列表，可以删除所有网站
3. 点击 **"更新"** 保存设置

**示例**：
```env
GOOGLE_SEARCH_ENGINE_ID=0123456789abcdefg:hijklmnopqr
```

**配置提示**：
- ✅ 必须启用"搜索整个网络"才能搜索任意网页
- ✅ 可以在"外观和风格"中自定义搜索结果的显示方式
- ✅ 可以配置语言和地区偏好以获得更相关的结果
- ⚠️ 免费版每天限制100次搜索请求
- 💡 如果需要更多配额，可以考虑升级到付费版本

**常见问题**：

**Q: 找不到"搜索整个网络"选项？**
A: 在创建搜索引擎时，先随意输入一个网站（如www.google.com），创建后在设置中启用"搜索整个网络"并删除该网站。

**Q: 搜索引擎ID在哪里？**
A: 登录 [Programmable Search Engine](https://programmablesearchengine.google.com/)，选择你的搜索引擎，在"概览"页面可以看到。

**Q: 可以使用多个搜索引擎ID吗？**
A: 可以创建多个搜索引擎，但WebSearcher一次只能配置一个ID。

## ⚙️ 搜索行为配置

### 6. MAX_RESULTS（最大结果数）

**说明**：每次搜索返回的默认最大结果数

**类型**：整数

**默认值**：`10`

**取值范围**：1-20

**是否必需**：否

**示例**：
```env
MAX_RESULTS=15
```

**说明**：
- 此值可以在调用工具时被`max_results`参数覆盖
- 较大的值会消耗更多API配额
- 不同搜索引擎可能有不同的限制：
  - Google：单次请求最多10个结果
  - Bing：单次请求最多50个结果
  - SerpAPI：取决于后端引擎

---

### 7. REQUEST_TIMEOUT（请求超时时间）

**说明**：搜索API请求的超时时间（秒）

**类型**：整数

**默认值**：`30`

**取值范围**：1-300（建议10-60）

**是否必需**：否

**示例**：
```env
REQUEST_TIMEOUT=45
```

**说明**：
- 超时时间过短可能导致搜索失败
- 超时时间过长会影响用户体验
- 建议根据网络状况调整

## 📊 日志和调试配置

### 8. LOG_LEVEL（日志级别）

**说明**：控制日志输出的详细程度

**类型**：字符串

**可选值**：
- `DEBUG` - 最详细，包含所有调试信息
- `INFO` - 一般信息，推荐用于生产环境
- `WARNING` - 仅警告和错误
- `ERROR` - 仅错误信息
- `CRITICAL` - 仅严重错误

**默认值**：`INFO`

**是否必需**：否

**示例**：
```env
LOG_LEVEL=DEBUG
```

**使用建议**：
- 开发/调试：使用`DEBUG`
- 生产环境：使用`INFO`或`WARNING`
- 问题排查：临时切换到`DEBUG`

---

### 9. DEBUG_MODE（调试模式）

**说明**：启用调试模式，输出更详细的错误信息

**类型**：布尔值

**可选值**：
- `true` / `1` / `yes` - 启用
- `false` / `0` / `no` - 禁用

**默认值**：`false`

**是否必需**：否

**示例**：
```env
DEBUG_MODE=true
```

**启用后的效果**：
- 显示完整的错误堆栈跟踪
- 输出详细的API请求/响应信息
- 不过滤敏感数据（仅用于开发）
- 自动将LOG_LEVEL设置为DEBUG

**安全提示**：
- ⚠️ 生产环境中不要启用DEBUG_MODE
- ⚠️ 调试模式可能会在日志中暴露API密钥等敏感信息

## 🔐 安全最佳实践

### 1. 保护API密钥

- ✅ 使用`.env`文件存储密钥
- ✅ 将`.env`添加到`.gitignore`
- ✅ 使用环境变量管理工具（如AWS Secrets Manager）
- ❌ 不要在代码中硬编码密钥
- ❌ 不要将密钥提交到版本控制

### 2. 最小权限原则

- 为API密钥设置适当的权限和配额限制
- 定期轮换API密钥
- 监控API使用情况

### 3. 生产环境配置

```env
# 生产环境推荐配置
SEARCH_ENGINE=serpapi
SERPAPI_KEY=${SECRET_SERPAPI_KEY}  # 从密钥管理服务获取
MAX_RESULTS=10
REQUEST_TIMEOUT=30
LOG_LEVEL=WARNING  # 减少日志输出
DEBUG_MODE=false   # 禁用调试模式
```

## 🎯 配置优先级

配置参数的优先级（从高到低）：

1. **MCP客户端配置**（Claude Desktop的`env`字段）
2. **系统环境变量**
3. **`.env`文件**
4. **代码默认值**

**示例**：如果在Claude Desktop配置中设置了`SEARCH_ENGINE=google`，即使`.env`文件中设置为`serpapi`，也会使用`google`。
