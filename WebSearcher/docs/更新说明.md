### 2. ✅ 配置参数详解

创建了详细的配置参数说明文档：**[配置参数说明.md](配置参数说明.md)**

#### 核心配置参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| **SEARCH_ENGINE** | 字符串 | `serpapi` | 搜索引擎选择：`google`、`bing`、`serpapi` |
| **SERPAPI_KEY** | 字符串 | - | SerpAPI密钥（使用SerpAPI时必需） |
| **GOOGLE_API_KEY** | 字符串 | - | Google API密钥（使用Google时必需） |
| **GOOGLE_SEARCH_ENGINE_ID** | 字符串 | - | Google搜索引擎ID（使用Google时必需） |
| **BING_API_KEY** | 字符串 | - | Bing API密钥（使用Bing时必需） |
| **MAX_RESULTS** | 整数 | `10` | 默认最大结果数（1-20） |
| **REQUEST_TIMEOUT** | 整数 | `30` | API请求超时时间（秒） |
| **LOG_LEVEL** | 字符串 | `INFO` | 日志级别：`DEBUG`、`INFO`、`WARNING`、`ERROR`、`CRITICAL` |
| **DEBUG_MODE** | 布尔值 | `false` | 调试模式开关 |

#### 参数详细说明

每个参数都包含：
- **说明**：参数的作用
- **类型**：数据类型
- **默认值**：默认配置
- **是否必需**：是否必须配置
- **获取方式**：如何获取API密钥等
- **示例**：配置示例
- **注意事项**：使用建议

详见：**[配置参数说明.md](配置参数说明.md)**

### 3. ✅ 远程MCP能力

实现了完整的远程MCP支持，使客户端和服务器可以分离部署。

#### 新增功能

##### 3.1 HTTP/SSE传输层

新增文件：`src/http_server.py`

**功能**：
- HTTP服务器实现
- Server-Sent Events (SSE) 支持
- JSON-RPC 2.0消息处理
- CORS支持

**HTTP端点**：
- `GET /health` - 健康检查
- `GET /sse` - SSE连接
- `POST /message` - JSON-RPC消息处理

##### 3.2 双模式启动

更新文件：`src/__main__.py`

**支持两种模式**：

1. **stdio模式**（本地）：
   ```bash
   python -m src.server --mode stdio
   ```

2. **HTTP模式**（远程）：
   ```bash
   python -m src.server --mode http --host 0.0.0.0 --port 8000
   ```

**命令行参数**：
- `--mode`: 传输模式（`stdio`或`http`）
- `--host`: HTTP服务器绑定地址
- `--port`: HTTP服务器监听端口

##### 3.3 依赖更新

更新文件：`pyproject.toml`

新增依赖：
```toml
"aiohttp>=3.9.0"  # HTTP服务器支持
```

## 🏗️ 架构对比

### 本地模式（stdio）

```
┌─────────────────────────────────────┐
│        同一台机器                    │
│                                     │
│  ┌─────────────┐   stdio           │
│  │ MCP Client  │◄──────────┐       │
│  │  (Claude)   │           │       │
│  └─────────────┘           │       │
│                            │       │
│  ┌─────────────────────────┴─────┐ │
│  │   MCP Server (WebSearcher)    │ │
│  └───────────────────────────────┘ │
└─────────────────────────────────────┘
```

**特点**：
- ✅ 简单易用
- ✅ 无需网络配置
- ❌ 客户端和服务器必须在同一台机器

### 远程模式（HTTP/SSE）

```
┌──────────────────┐         ┌──────────────────────┐
│   客户端机器      │         │     服务器机器        │
│                  │         │                      │
│  ┌────────────┐  │  HTTP   │  ┌────────────────┐  │
│  │ MCP Client │  │◄───────►│  │  HTTP Server   │  │
│  │  (自定义)  │  │   SSE   │  │ (WebSearcher)  │  │
│  └────────────┘  │         │  └────────────────┘  │
│                  │         │          │           │
│                  │         │          ▼           │
│                  │         │  ┌────────────────┐  │
│                  │         │  │  Search Engine │  │
│                  │         │  │      API       │  │
│                  │         │  └────────────────┘  │
└──────────────────┘         └──────────────────────┘
```

**特点**：
- ✅ 客户端和服务器可以分离
- ✅ 支持多个客户端共享
- ✅ 便于集中管理
- ✅ 可部署到云服务器

## 🚀 快速开始

### 本地模式

```bash
# 1. 配置环境变量
cp .env.example .env
# 编辑.env添加API密钥

# 2. 在Claude Desktop配置
# 编辑 ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "websearcher": {
      "command": "python",
      "args": ["-m", "src.server"],
      "cwd": "/path/to/WebSearcher",
      "env": {
        "SEARCH_ENGINE": "serpapi",
        "SERPAPI_KEY": "your_key"
      }
    }
  }
}

# 3. 重启Claude Desktop
```

### 远程模式

```bash
# 1. 安装依赖
pip install -e .

# 2. 配置环境变量
cp .env.example .env
# 编辑.env添加API密钥

# 3. 启动HTTP服务器
python -m src.server --mode http --host 0.0.0.0 --port 8000

# 4. 验证服务器
curl http://localhost:8000/health

# 5. 使用客户端示例测试
python examples/remote_client_example.py
```

## 🔍 常见问题

### Q1: 如何选择使用哪种模式？

**本地模式（stdio）**：
- 个人使用
- 简单场景
- 不需要远程访问

**远程模式（HTTP）**：
- 团队共享
- 云部署
- 需要集中管理
- 多客户端访问

### Q2: 远程模式是否安全？

远程模式需要额外的安全配置：
- 使用HTTPS加密
- 配置认证授权
- 启用防火墙
- 使用速率限制

详见[远程部署指南.md](远程部署指南.md)的安全章节。

### Q3: 如何获取API密钥？

详见[配置参数说明.md](配置参数说明.md)中每个搜索引擎的获取方式。

推荐使用SerpAPI（最简单）：
1. 访问 https://serpapi.com/
2. 注册账号
3. 获取API密钥
4. 免费额度：100次搜索/月

### Q4: 远程模式的性能如何？

性能取决于：
- 网络延迟
- 服务器配置
- 搜索引擎API响应时间

优化建议：
- 使用CDN
- 启用结果缓存
- 配置合理的超时时间
- 使用负载均衡
